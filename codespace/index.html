ONLINE ENVIRONMENT SETUP

GitHub Codespace で始めるプログラミング

GitHub アカウント登録から、授業用リポジトリへのアクセス、Codespace の起動、C言語の Hello, World 実行、終了手順までをまとめたチュートリアルです。

手順を始める 授業用リポジトリ Codespaces 管理画面
codespace / terminal
# ここまでできれば準備完了
$ gcc hello.c -o hello
$ ./hello
Hello, World!

# 作業後は忘れずに停止
Menu Codespaces > Stop Current Codespace

Overview

今日やること

ブラウザだけでC言語の開発環境を起動し、最初のプログラムを実行します。ソフトウェアのインストールが不要なので、授業用PC以外からでも同じ手順で作業できます。

1GitHubアカウントを作成する
2授業用リポジトリにアクセスする
3Codespaceを起動する
4Hello, Worldを実行する
5Codespaceを終了する

Preparation

始める前に準備するもの

必要なもの

  • インターネットに接続されたパソコン
  • メールアドレス。大学のメールアドレス推奨: s12345@cc.ashikaga.ac.jp
  • ブラウザ。Chrome、Edge、Firefox など

注意

  • GitHubアカウント作成には数分かかります。
  • メール認証が必要です。受信できるアドレスを使ってください。
  • すでにアカウントがある場合は、新規作成せず Sign in します。

Part 1

GitHubアカウントを作成する

  1. ブラウザで https://github.com/ にアクセスします。
  2. 画面右上の Sign up をクリックします。
  3. メールアドレス、パスワード、ユーザー名を入力します。ユーザー名は半角英数字とハイフンが使えます。
  4. 画面の指示に従い、認証を完了します。
  5. GitHubから届く確認メールを開き、認証コード入力または Verify email address を実行します。

メールが届かないとき: 迷惑メールフォルダを確認し、数分待っても届かない場合は Resend email を試してください。

Part 2

授業用リポジトリにアクセスする

リポジトリは、プログラムや関連ファイルを保管する場所です。この授業では ashikaga-prog1 の組織ページから、指定されたリポジトリを開きます。

  1. GitHubにログインした状態で、授業用リポジトリ一覧を開きます。
    https://github.com/orgs/ashikaga-prog1/repositories
  2. 授業で指定されたリポジトリ名を探してクリックします。
  3. リポジトリのトップページが開いたら、README.md などの説明を確認します。

補足: リポジトリ名は授業回や実施内容に応じて変わります。指定がある場合は、その名前を優先してください。

Part 3

Codespaceを起動する

Codespaceは、ブラウザ上で使えるVS Codeベースの開発環境です。授業用リポジトリから起動します。

  1. リポジトリページの右上付近にある緑色の Code ボタンをクリックします。
  2. 表示されたメニューで Codespaces タブを選びます。
  3. Create codespace on main をクリックします。
  4. セットアップが完了するまで待ちます。初回は少し時間がかかります。
  5. ブラウザ内にエディタ、ファイル一覧、ターミナルが表示されれば起動完了です。

起動しないとき: ネットワークを確認し、ブラウザを再読み込みします。それでも進まない場合は、GitHubのCodespaces管理画面から該当Codespaceを削除して作り直すことがあります。

Part 4

Hello, Worldプログラムを作成・実行する

Hello, Worldは、新しい言語や環境を学ぶときに最初に作る小さなプログラムです。C言語の基本形を確認します。

1. ファイルを作成する

  1. 左側のファイル一覧で、新しいファイルを作成します。
  2. ファイル名を hello.c にします。拡張子 .c が重要です。
  3. 以下のコードを入力します。
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

2. コンパイルする

下部の Terminal を開き、次のコマンドを実行します。

gcc hello.c -o hello

3. 実行する

コンパイルが成功したら、次のコマンドで実行します。

./hello

ターミナルに Hello, World! と表示されれば成功です。

コードの意味: #include <stdio.h> は画面出力を使う準備、int main(void) はプログラムの開始点、return 0; は正常終了を表します。

Part 5

作業を保存し、Codespaceを終了する

Codespaceはクラウド上で動くため、使い終わったら停止します。ブラウザのタブを閉じるだけでは、しばらく動き続ける場合があります。

作業をGitHubに保存する

  1. 左側の Source Control を開きます。
  2. 変更内容が分かるメッセージを入力します。例: Add hello world program
  3. Commit をクリックします。
  4. Sync Changes または Push をクリックし、GitHub上のリポジトリへ反映します。

Codespaceを停止する

  1. Codespace画面左上のメニューを開きます。
  2. Codespaces を選択します。
  3. Stop Current Codespace をクリックします。
  4. 停止完了の表示を確認してから、ブラウザを閉じます。

無料枠を守るコツ: 作業が終わったら必ず停止します。不要になった環境は Codespaces管理画面 から削除できます。

Troubleshooting

よくあるつまずき

メール認証が届かない

  • 迷惑メールフォルダを確認します。
  • メールアドレスの入力ミスを確認します。
  • Resend email を押します。

コンパイルでエラーが出る

  • セミコロン ; の付け忘れを確認します。
  • 波かっこ { } の対応を確認します。
  • 全角記号が混ざっていないか確認します。

Finish

確認リスト

  • GitHubアカウントを作成し、メール認証を完了した。
  • 授業用リポジトリにアクセスできた。
  • Codespaceを起動できた。
  • hello.c を作成し、Hello, World! を表示できた。
  • 変更を保存し、Codespaceを停止できた。
