ONLINE ENVIRONMENT SETUP

GitHub & Codespaces

ブラウザ上でC言語プログラミングを行うためのオンライン環境構築手順

1. GitHubアカウントの作成

Codespacesを利用するには、まずGitHubのアカウントが必要です。以下の手順で無料で作成できます。

  1. GitHub公式サイト にアクセスします。
  2. 右上の「Sign up」ボタンをクリックします。
  3. メールアドレス、パスワード、ユーザー名を入力し、指示に従って登録を完了させます。（大学のメールアドレスを利用することを推奨します）
  4. 登録したメールアドレスに認証メールが届くので、リンクをクリックしてアカウントを有効化します。

2. Git / GitHubの基本用語

プログラミング演習や開発で頻繁に登場するGit（ギット）とGitHub（ギットハブ）の基本用語を説明します。

  • リポジトリ (Repository)：プログラムのソースコードや変更履歴を保存しておく「貯蔵庫」のことです。
    • パブリック (Public)：世界中の誰でも見ることができる設定です。
    • プライベート (Private)：自分や許可した人しか見られない設定です。※講義の課題などを保存する場合は、他の受講生に見られないように必ず「プライベート」を選択してください。
  • コミット (Commit)：ファイルの変更履歴を記録（セーブ）することです。意味のある区切りごとにコミットします。
  • プッシュ (Push)：手元の環境（Codespacesや自分のPC）でコミットした変更を、GitHub上のリモートリポジトリに送信・反映させることです。

3. Codespaceの利用環境設定

GitHub Codespacesは、ブラウザ上で動作する完全な開発環境（VS Codeベース）です。ソフトウェアのインストール不要でC言語の開発が可能です。

リポジトリの作成とCodespaceの起動

  1. GitHubにログインし、新しいリポジトリ（Repository）を作成します。
  2. リポジトリのページで、緑色の「<> Code」ボタンをクリックし、「Codespaces」タブを選択します。
  3. 「Create codespace on main」をクリックすると、ブラウザ内でVS Codeに似たエディタが起動します。

C言語環境のセットアップ

通常、Codespacesのデフォルト環境（Linux）にはCコンパイラ（GCC）が既にインストールされています。確認のために、下部の「Terminal」タブを開き、以下のコマンドを入力してください：

gcc --version

バージョン情報が表示されれば、すぐにC言語のコンパイルと実行が可能です。

推奨される拡張機能のインストール

より快適にプログラミングを行うために、C言語向けの拡張機能をインストールしましょう。

  1. 画面左側のアイコン一覧から「Extensions（拡張機能）」をクリックします。
  2. 検索バーに C/C++ と入力します。
  3. Microsoftが提供している「C/C++」拡張機能を見つけ、「Install（インストール）」をクリックします。

これにより、コードの自動補完（サジェスト）や構文エラーの強調表示などが有効になります。

4. Hello, World! の実行

実際にC言語のプログラムを作成し、実行してみましょう。

ファイルの作成とコードの入力

  1. 画面左側の「Explorer（エクスプローラー）」を開き、新しいファイルを作成するアイコンをクリックします。
  2. ファイル名を hello.c とします（拡張子 .c が重要です）。
  3. 作成したファイルに以下のコードを入力します：
#include <stdio.h> int main(void) { printf("Hello, World!\n"); return 0; }

コンパイルと実行（.exeファイルの生成）

入力が完了したら、プログラムを実行可能な形式に変換（コンパイル）します。

  1. Terminal（ターミナル）を開きます。
  2. 以下のコマンドを入力してコンパイルします（-o hello.exe は出力するファイル名を指定しています）：
gcc hello.c -o hello.exe

※Codespacesの標準環境はLinuxですが、演習の便宜上、出力ファイル名にWindowsの実行形式である .exe を付けています。

  1. コンパイルが成功すると、hello.exe というファイルが生成されます。以下のコマンドで実行します：
./hello.exe

画面に Hello, World! と表示されれば成功です！

5. ファイルのダウンロード

Codespaces上で作成したファイルや生成されたファイルを、自分のパソコンに保存（ダウンロード）することができます。課題の提出時などに利用します。

  • ソースファイル（.c）：あなたが書いたプログラムのソースコードです。課題提出では主にこちらのファイルを提出します。
  • 実行ファイル（.exeなど）：コンパイルして出来上がった実行可能なファイルです。パソコンの環境によってはそのまま実行できないことがあります。

ダウンロード手順

  1. 左側のエクスプローラーから、ダウンロードしたいファイル（例：hello.c または hello.exe）を右クリックします。
  2. メニューから「Download（ダウンロード）」を選択します。
  3. ブラウザの通常のダウンロード機能を通じて、手元のパソコンにファイルが保存されます。

6. 講義終了時の保存と片付け

実習が終わったら、作成したプログラムをGitHubに保存し、Codespaceを確実に終了させましょう。

1. リポジトリへのコミットとプッシュ

  1. 画面左側の「Source Control（ソース管理）」アイコン（枝分かれしたマーク）をクリックします。
  2. 「Message」の入力欄に「課題の完了」など、作業内容がわかるコメントを入力します。
  3. 「Commit」ボタンをクリックして、変更をコミット（記録）します。（※「変更をステージしますか？」と聞かれたら「Yes（はい）」を選びます）
  4. 「Sync Changes（変更の同期）」または「Push」をクリックして、GitHub上のリポジトリに変更を反映（アップロード）させます。これで保存は完了です。

💡 プッシュの重要性
変更をGitHub上のリポジトリにプッシュしておけば、無料枠節約のためにCodespace本体を「Delete（削除）」しても、ファイルやコードはGitHub上に安全に残ります。次回は同じリポジトリから新しいCodespaceを作り直すだけで、続きから作業を再開できます。

2. Codespaceのターミネート（終了）

【重要】 ブラウザのタブを閉じるだけではCodespaceはすぐに終了せず、バックグラウンドで動き続けて無料枠を消費してしまいます。

  1. 画面左下にある青色（または緑色）の「><」アイコンをクリックします。
  2. 画面上部に出てくるメニューから 「Stop Current Codespace」 を選択します。
  3. 画面が切り替わり停止状態になれば、安全にブラウザを閉じて終了できます。

7. 無料枠での実習対応に関する注意

GitHub Codespacesは、個人アカウント向けに毎月一定時間（標準で120コア時間/月など）の無料枠が提供されています。

【重要】無料枠を使い切らないための対策

  • 必ず停止する: 作業が終わったら、画面左下の「><」アイコン（Codespacesメニュー）から「Stop Current Codespace」を選択し、明示的に停止させてください。
  • タブを閉じるだけでは不十分: ブラウザのタブを閉じただけでは、一定時間（デフォルト約30分）バックグラウンドで起動し続け、無料枠を無駄に消費してしまいます。
  • 不要なCodespaceの削除: Codespacesの管理画面から、使わなくなった環境はこまめに削除しましょう。

授業での実習（週1回の講義と課題）であれば、こまめに停止して無駄なアイドル時間を減らせば、無料枠内で十分に賄うことができます。
